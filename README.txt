JianJian Ultimate — Build 1402
課表與菜單同步修正版

修正內容：
1. 菜單不再只依重訓／有氧／休息分類。
2. 菜單會同時依照：
   - 目前目標：降低體脂、增加肌肉、體態重塑、提升力量、健康維持
   - 當天課表：重訓、有氧、休息
   自動決定建議熱量、蛋白質與餐點。
3. 使用「依目標生成課表」後，會同步重建今天與未來 28 天：

   - 熱量目標
   - 蛋白質目標
4. 編輯每週課表後，也會同步重建未來 28 天菜單。
5. 快速套用個人計畫後，也會同步。
6. 修正「臀腿優先減脂」使用錯誤 focus 名稱，現在會正確加入臀腿重點。
7. 過去日期及過去紀錄不會刪除。
8. 不修改登入、好友、動作教學與既有資料格式。

測試：
- 我的 → 依目標生成課表 → 選「增加肌肉」
- 回首頁確認課表改變
- 打開菜單，標題應顯示「增加肌肉・重訓日菜單」等文字
- 切換到休息日，菜單應切換為休息日內容
- 改選「降低體脂」後，熱量及菜單內容應一起降低


JianJian Ultimate — Build 1403
課表目標設定儲存版

新增：
- 「儲存目前設定」按鈕。
- 可保存目標、每週天數與偏好，而不重新建立課表。
- 儲存沿用原本 save() 流程：
  1. 先寫入 localStorage
  2. 已登入時再透過既有 syncCloud() 同步 Firestore
- 「生成並套用」也會同步保存三項設定。
- 重新開啟「我的」頁時會讀回已保存的設定。
- 顯示最後儲存時間。

操作：
- 只想記住選項：按「儲存目前設定」。
- 想重新生成課表與菜單：按「生成並套用」。
